
# 🛡️ PhishGuard – Phishing Awareness & URL Safety Tool

## 📌 About the Project
PhishGuard is a web-based phishing awareness and URL safety tool designed to help users understand phishing attacks, identify suspicious URLs, and improve their online security.

**Tagline:** Pause. Verify. Protect.

## ✨ Features
- 🏠 **Home:** Introduction to PhishGuard.
- 📚 **Awareness:** Learn about phishing attacks.
- 🔍 **URL Checker:** Check a URL for suspicious signs.
- 🛡️ **Safety Tips:** Learn safe internet practices.
- 📝 **Quiz:** Test your phishing awareness knowledge.
- 🎨 **Modern UI:** Dark theme with blue highlights.

## 🛠️ Technologies Used

## 🚀 How to Run the Project
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Alternatively, use the **Live Server** extension in VS Code.
5. Navigate through Home, Awareness, URL Checker, Safety Tips, and Quiz.

## 🔍 How to Use the URL Checker
1. Open the URL Checker section.
2. Enter the URL you want to inspect.
3. Click **Scan URL**.
4. Review the result displayed by the tool.
5. You can also click **Try a sample URL**.

> **Note:** This is a basic educational checker. It cannot guarantee that a URL is safe or detect every phishing website. Do not enter passwords, OTPs, or other sensitive information into suspicious websites.

## 🛡️ Safety Tips
- Never share your password or OTP.
- Check website domains carefully.
- Avoid clicking suspicious links.
- Do not trust messages that create unnecessary urgency.
- Verify requests through official websites or contact details.
- Enable two-factor authentication whenever possible.

## 🎯 Project Objective
The main objective of PhishGuard is to spread cybersecurity awareness and help users recognize common phishing warning signs through an interactive website.
